# Refactors

Notas de especificación de refactors, organizadas por feature.

- `NNN-<feature>/` — refactors de una feature concreta (mismo `NNN` que `spec/features/`).
  - `001-registro-incidencia/` — `payload-incidencia-inline.md`, `alineacion-contrato-incidencia.md`,
    `conexion-incidencia-backend-multipart.md`.
- `infra/` — refactors de infraestructura transversal que no pertenecen a una feature
  (p. ej. `nativewind-migracion-pendiente.md`).

Los enlaces entre notas de la misma carpeta son relativos (`./otro.md`).
