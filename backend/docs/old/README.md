# Archivo histórico del backend

[spec/reports/](spec/reports/) conserva los informes antiguos y sus resultados originales. Son referencias históricas; no se utilizan como instrucciones vigentes ni acreditan el estado actual de la API.

Las especificaciones y planes existentes se agruparon en [spec/features/](../spec/features/) sin descartar su contenido. Los cambios nuevos siguen la [organización documental actual](../spec/README.md) y registran la confirmación en el propio plan o documento del cambio.
