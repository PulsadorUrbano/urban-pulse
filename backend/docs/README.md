# Backend documentation

Backend documentation is organized by document type:

- `adr/`: architecture decision records.
- `c4/`: architecture diagrams.
- `migrations/`: database migration and schema reference files.
- `spec/features/specs/`: feature specifications.
- `spec/features/plans/`: implementation plans for features.
- `spec/reports/`: implementation reports.

Add new feature specifications and plans under `spec/features/`, keeping plans and their corresponding specifications in the respective `plans/` and `specs/` folders. Store reports in `spec/reports/`. Use relative links between related documents.
